## Key Questions to Ask
1. Is the app intended to be developed for iOS, Android, or both (cross-platform)?

2. Would you like the app to be deployed on an actual mobile device, or would a version that runs on a computer for testing and demonstrating the concept be sufficient?  
 Note: Deploying to a real device will require additional time. If deployment is needed, we may need to simplify certain features.

3. Regarding user types, should we currently focus only on regular users?  
 Note: If enterprise users are to be included, we will need to design different interfaces for different user types.

4. For the UI, should we modify the design based on what was shown in the previous PPT, or would you like us to create a new design from scratch? If there are specific UI requirements (e.g., logos, images), please provide the relevant assets.  
 Note: It would be helpful to confirm a primary theme color — for example, the home screen could use a light blue or teal tone.

5. Below is a breakdown of the proposed features and our questions for clarification:  
5.1. Mood Check-in  
 Users can record their emotional state each day, with the option to select mood tags or write a brief note.  
 Questions: (1) Will this be collected in the form of a questionnaire? (2) Should we include extended visual analysis and presentation?  
5.2. Quick Notes  
 Allows users to quickly record daily events, ideas, or work-related notes — similar to a diary or memo.  
5.3. Community Sharing  
 Users can post updates and interact with others, with support for likes and comments.  
 Question: Will these two features (Quick Notes and Community Sharing) be kept as separate modules, or should they be integrated into one? For example, a private post could serve as a diary, while a public post would appear as a community post.  
5.4. Interest Subscription  
 Users can choose topics or content areas of interest, and the system will push related content accordingly.  
5.5. Rewards System  
 Users can earn points or badges for completing tasks or check-ins, encouraging continuous engagement.  
 Question: Should regular users only be able to participate while enterprise users can edit and publish, or should regular users also be able to publish?  
5.6. Offline Connections  
 Pushes local events and offline social opportunities, with options for users to register and attend.  
 Question: Should this be implemented like a “nearby people” chat/message feature, or should events be displayed on a map?  
5.7. Challenge Participation  
 Allows users to initiate or participate in themed challenges, with rewards for consecutive participation or completion rates.
