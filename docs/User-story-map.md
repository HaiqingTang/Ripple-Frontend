# User Story Map

**Overview**<br>
The User Story Map provides a graphical summary of all user stories for the Ripple App.  
Our project is a collaborative effort between two teams:  

- **RP-Koala** is responsible for the following backbone features:  
  1. Login  
  2. Mood States  
  3. Topic Search  
  4. Personal Logs  

- **RP-Wombat** is responsible for the following backbone features:  
  1. Interest Subscription  
  2. Offline Meeting  
  3. Challenge System  
  4. Reward System  

Below are the User Story Maps from both teams, which together represent the full scope of the Ripple App.
