## Requirements Analysis (User Stories)
### What Needs More Work

Some user stories are too ambitious for an MVP (e.g., complex filtering in US-MOOD-004, comments in US-COMM-003). These are flagged as “to remove” but still included.

All user stories are currently marked as High priority. It would be better to apply MoSCoW prioritization (Must/Should/Could) to distinguish essential MVP features from stretch goals.

Workload-to-capacity alignment is unclear, as no estimation is provided for 11 user stories across 5 members. Adding lightweight estimation (e.g., T-shirt sizing) would ensure achievability within the 8-week timeframe.

### Action Items

1.  Remove or reframe ambitious user stories that are not MVP-ready.

2.  Apply MoSCoW prioritization to all user stories.

3.  Add T-short estimation for each user story.
